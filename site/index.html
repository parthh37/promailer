220 Service ready

The IIS 6 SMTP service, rebuilt for today’s Windows Server.

Promailer takes mail from your applications over SMTP, the Pickup directory or an HTTP API, signs it with DKIM and delivers it with retries and bounce handling. It runs as one Windows service, and every IIS 6 setting has a place in it.

250 Settings you already know

Move over without relearning anything.

Your applications keep the same Pickup folder and port 25. Relay rules, smart host, retry intervals and the badmail folder all carry over. Each IIS 6 property has a setting in promailer.toml, and Promailer Manager lays them out like the MMC snap-in you used before.

354 Start sending

Running in four steps.

  1. Install

    Run Promailer-x.y.z-x64-Setup.exe as Administrator. It installs the service, the Manager, a desktop shortcut and the status icon, and can switch off the IIS SMTP service for you.

  2. Name the server

    Enter the host name that matches your IP’s reverse DNS, for example mail.example.com. Setup writes it to C:\ProgramData\Promailer\promailer.toml.

  3. Point your applications at it

    SMTP on localhost:25 works unchanged, and so does the .NET Pickup directory:

    var client = new SmtpClient {
    DeliveryMethod = SmtpDeliveryMethod.SpecifiedPickupDirectory,
    PickupDirectoryLocation = @"C:\ProgramData\Promailer\pickup"
};

  4. Check your DNS

    Gmail, Outlook and Yahoo expect PTR, SPF, DKIM and DMARC. Promailer tells you exactly what to publish:

    promailer dkim generate --domain example.com --selector s1
promailer check --domain example.com
